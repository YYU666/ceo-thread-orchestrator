# Code Of Conduct

This project should be a practical, respectful place to discuss Codex orchestration, agent workflows, and project-management patterns.

## Expected Behavior

- Be respectful and specific.
- Critique ideas, prompts, and behavior, not people.
- Assume contributors may have different Codex versions, tool access, and workflows.
- Keep reports factual and reproducible when possible.
- Avoid sharing private credentials, private paths, or unsanitized conversation logs.

## Unacceptable Behavior

- Harassment, insults, threats, or personal attacks.
- Publishing private information without permission.
- Repeatedly derailing issues or pull requests.
- Submitting secrets, tokens, or private workflow details as examples.

## Enforcement

Maintainers may edit, hide, or remove comments and contributions that violate this code of conduct. Repeated or severe violations may result in blocked participation.

If you need to report a problem, open a GitHub issue with relevant context and avoid including private information.
